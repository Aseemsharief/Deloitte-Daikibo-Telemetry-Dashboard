# Factory & Device Downtime Analysis (Deloitte Data Analytics Simulation)

![Dashboard Preview](dashboard_preview.png)

## Project Overview
Analyzed industrial machine telemetry data (daikibo-telemetry-data.json) as part of the Deloitte Data Analytics Job Simulation (Forage) to identify equipment failure patterns and manufacturing bottlenecks.

## Tools Used
* Tableau Desktop: Data modeling, calculated fields, and interactive dashboarding
* JSON Telemetry Data: Multi-location factory sensor logs

## Key Findings
* Factory-Level Downtime: Identified the specific manufacturing plant experiencing the highest unhealthy machine downtime.
* Device-Level Bottleneck: Pinpointed LaserCutter devices as the primary driver of equipment downtime compared to other machine types.
* Recommendation: Suggested preventive maintenance scheduling for high-downtime LaserCutter units to reduce operational delays.
